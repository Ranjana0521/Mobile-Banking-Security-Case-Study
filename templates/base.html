SecureBank Educational Security Demonstration

Implemented as an engineering case study to counter mobile banking threats. Demonstrates runtime application self-protection (RASP), anti-phishing mutual visual authentication, AES-256-GCM authenticated encryption at rest, memory-hard Scrypt password hashing, and dynamic HMAC-SHA256 one-time authentication tokens.

CRYPTOGRAPHIC SPECIFICATION
  • KDF: scrypt (N=16384, r=8, p=1, dklen=32)
  • AEAD Cipher: AES-256-GCM (12-byte Nonce, 16-byte Tag)
  • MFA OTP: HMAC-SHA256 (Salted, 180s Time-Bound)
  • Ledger Hash: SHA-256 Merkle-Chained Blocks
